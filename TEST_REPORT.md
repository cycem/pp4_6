# Отчёт о тестировании

## 1. Объект тестирования

LibraryApp – консольное приложение на C# (.NET 8) для учёта книг в библиотеке. Поддерживает добавление книг, выдачу, возврат и поиск по Id.

Основные сущности:
- `Book` – книга (Id, Title, Author, IsAvailable);
- `Library` – хранилище книг и бизнес-логика выдачи и возврата;
- `LibraryException` и его наследники – исключения для ожидаемых ошибок.

## 2. Методика тестирования

- **Ручное тестирование.** Запуск приложения и проверка сценариев: выдача, повторная выдача, возврат, возврат невыданной книги, работа с несуществующим Id.
- **Отладка.** Точки останова в `BorrowBook`, `ReturnBook`, `FindBook`; пошаговое выполнение (F10, F11); наблюдение за значениями в окнах «Локальные» и «Контрольные значения».
- **Статический анализ.** Анализаторы кода Visual Studio (уровень анализа – рекомендуемый), проверка предупреждений в «Списке ошибок», ревизия кода на соответствие стандартам именования, наличие XML-документации и обработку исключений.

## 4. Результаты инспекции кода

Замечания:
1. Вывод на экран внутри `Library` смешан с логикой. **Исправлено:** вывод перенесён в `Program`.
2. Отсутствие проверки null в `AddBook`. **Исправлено:** `ArgumentNullException`.
3. Отсутствие проверки уникальности Id. **Исправлено:** `ArgumentException`.
4. Предупреждение nullable в `FindBook`. **Исправлено:** возвращаемый тип `Book`.
5. Нет XML-документации у публичных членов. **Исправлено:** добавлена.
6. Отсутствие обработки исключений. **Исправлено:** собственные исключения и `try/catch` в `Run`.
7. Дублирование проверки null в `BorrowBook` и `ReturnBook`. **Исправлено:** метод `GetBookOrThrow`.
8. Длинные методы. **Исправлено:** логика разбита на вспомогательные методы.
9. Неточное сообщение «нет в наличии». **Исправлено:** текст уточнён.

Соответствие именования PascalCase/camelCase проверено, замечаний не выявлено. Пустых `catch` и перехвата `Exception` нет.
