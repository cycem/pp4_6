# LibraryApp

Консольное приложение на C# для учёта книг в библиотеке: добавление, выдача, возврат и поиск по Id.

## Требования

.NET 8 SDK (или Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET»)

## Запуск

Через Visual Studio: откройте `LibraryApp.sln` и нажмите F5.

## Структура проекта

- `Book.cs` — модель книги;
- `Library.cs` — бизнес-логика выдачи и возврата;
- `Exceptions.cs` — исключения библиотеки;
- `Program.cs` — точка входа и демонстрация сценариев.
